# Atelier — Event Builder

Prototype V0 d’un builder universel de sites événementiels.

## Lancer le projet

```bash
npm install
npm run dev
```

## V0 incluse

- Dashboard de projets et dossiers
- Création guidée d’un événement
- Kits mariage, anniversaire, entreprise, festival, conférence et soirée
- Sitemap généré et réorganisable
- Design Studio avec directions artistiques, palettes et typographies
- Builder de page avec aperçu desktop/mobile
- Aperçu visiteur
- Persistance locale des projets via `localStorage`
